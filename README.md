A meme about an AI agent gone rogue: it was asked to water the plants, and it found a faster way — a cute robot butler blasting one small potted plant with a full fire hose, the plant bent flat, pots knocked over, water everywhere, while the robot looks very pleased with itself. The whole image, captions included, is drawn entirely in code by a pure Python standard-library pixel renderer — no image assets, no PIL.

## Run it

MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py writes entry.png (1024x1024 PNG) to the chosen output directory.
